# SKYCOIN4444 Standalone Product Master Plan

Product #9: **Sky Workflow**.

Sky Workflow is the independently deployable workflow/scheduling service. Its target is explicit workflow definitions, deterministic step transitions, retries/backoff, cancellation, timeout handling, idempotent execution records, execution history, health/readiness/metrics, container packaging, and exact-head CI evidence.

The repository name is historical; shipped runtime/language claims must match the implementation actually present.

Future SKYCOIN4444 integration occurs through versioned workflow contracts. No distributed exactly-once execution or HA guarantee is claimed unless implemented and verified.
